# Knowledge Hub Pages

Public static knowledge library: https://hustwyk.github.io/knowledge-hub-pages/

This repository currently contains an empty site shell. No archived articles, private notes, source snapshots, credentials or databases have been published.

GitHub Pages serves `main:/docs`; commits to that directory trigger GitHub's Pages build and deployment. The initial shell requires no package install, CDN or build dependencies. After cloning, open `docs/index.html` locally for offline viewing.

Future exports must contain only explicitly approved derived content tied to its reviewed revision. This public repository is a replica of the approved public subset, not a complete backup of the private knowledge service. Full search and model-backed questions belong to the authenticated application.
